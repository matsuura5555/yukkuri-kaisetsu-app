ゆっくり解説の YouTube チャンネルのための個人用ツール

ゆっくり解説 投稿・分析ツール

このページは、ゆっくり解説の YouTube チャンネルの持ち主が、自分のチャンネルのためだけに使う個人用のツールの説明です。 一般に公開しているサービスではありません。

  • プライバシーポリシー
  • お問い合わせ

このツールでできること

  • 持ち主が作った動画を、持ち主の YouTube チャンネルに投稿します。投稿は「非公開」で行い、持ち主が内容を確かめてから公開します。
  • 投稿した動画に、サムネイル（表紙の画像）と日本語の字幕を設定します。
  • 持ち主のチャンネルの視聴データ（再生回数、どこまで見られたか、どこから見に来たか、表示回数とクリック率など）を読みます。
  • 持ち主の動画に寄せられたコメントを読みます。

読んだデータは、次の動画の台本や作り方を直すことに使います。 ツールは持ち主の PC の中で動くプログラムで、データを集めるためのサーバーはありません。

使う人

使うのはチャンネルの持ち主1人だけです。ほかの人に配ったり、ほかの人の Google アカウントで使ったりはしません。

使う Google の権限

このツールは YouTube API サービスを使います。持ち主の Google アカウントで、次の権限を許可して使います。

  • YouTube への動画の投稿 youtube.upload
    持ち主のチャンネルに動画を投稿します。
  • YouTube のデータの閲覧・管理 youtube.force-ssl
    投稿した動画のサムネイル・字幕の設定と、公開・予約公開への切りかえ（持ち主が確かめたあと）に使います。持ち主の動画へのコメントを読むのにも使います。コメントへの返信・削除や、動画の削除はしません。
  • YouTube のデータの閲覧 youtube.readonly
    持ち主のチャンネルと動画の情報（タイトル、再生回数など）を読みます。視聴データの問い合わせにも必要です。
  • YouTube Analytics の閲覧 yt-analytics.readonly
    持ち主の動画の視聴データ（再生回数、総再生時間、視聴維持率、流入元、YouTube 検索の検索語、表示回数とクリック率など）を読みます。
  • 収益レポートの閲覧 yt-analytics-monetary.readonly
    チャンネルで収益化を始めたときに、持ち主の動画の収益と広告のデータを読むためのものです。いまは読んでいません。

Google アカウントのメールアドレス・名前・連絡先や、YouTube 以外の Google サービスのデータは読みません。 取得する情報と、その扱いはプライバシーポリシーに書いています。

このツールは YouTube API サービスを使っています。このツールを使うことで、 YouTube 利用規約に同意したことになります。 Google によるデータの扱いは、Google プライバシー ポリシーをご覧ください。
