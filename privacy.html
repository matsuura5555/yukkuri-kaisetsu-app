ゆっくり解説 投稿・分析ツール

プライバシーポリシー

このプライバシーポリシーは、ゆっくり解説の YouTube チャンネルの持ち主（以下「持ち主」）が、自分のチャンネルのために使う個人用のツール 「ゆっくり解説 投稿・分析ツール」（以下「このツール」）が、Google アカウントと YouTube の情報をどう扱うかを説明するものです。 このツールを使うのは持ち主1人だけで、一般には公開していません。

1. YouTube API サービスの利用

このツールは YouTube API サービスを使っています。このツールを使うことで、 YouTube 利用規約に同意したことになります。 Google による情報の扱いについては、Google プライバシー ポリシーをご覧ください。

2. 取得する情報

このツールは、持ち主が許可した権限の範囲で、持ち主のチャンネルについての次の情報を取得します。

持ち主のチャンネルと動画の情報

  • チャンネルの ID、動画の ID・タイトル・公開の状態・長さ
  • 動画の再生回数・高評価の数・コメントの数

視聴データ（YouTube Analytics API・YouTube Reporting API）

  • 再生回数、総再生時間、平均視聴時間、平均視聴率、高評価・コメント・共有の数、チャンネル登録者の増減
  • 視聴維持率（動画のどこまで見られたか）、流入元（どこから見に来たか）、YouTube 検索の検索語
  • サムネイルの表示回数とクリック率
  • チャンネルで収益化を始めたときは、収益と広告のデータ（いまは取得していません）

視聴データは YouTube が集計した数字で、見た人一人ひとりを特定できる情報は含みません。

持ち主の動画に寄せられたコメント

  • コメントと返信の本文、投稿した人の表示名、投稿日時、高評価の数、持ち主自身のコメントかどうか

これらは YouTube 上で公開されているコメントです。投稿した人のメールアドレスなどは取得できず、取得しません。

認証の情報

  • Google が発行するアクセス トークンとリフレッシュ トークン（このツールが API を使うための鍵）

取得しない情報

  • Google アカウントのメールアドレス・名前・電話番号・連絡先
  • YouTube 以外の Google サービス（Gmail、Google ドライブ、カレンダーなど）のデータ
  • 持ち主以外の人のチャンネルの非公開の情報

YouTube に送る情報

動画を投稿するとき、このツールは持ち主が作った動画のファイル・タイトル・説明文・タグ・サムネイル・字幕を YouTube に送ります。 投稿は「非公開」で行い、公開・予約公開への切りかえは持ち主が確かめてから行います。

3. 情報の使い道

取得した情報は、持ち主本人が、自分のチャンネルに動画を投稿し、その動画を分析するためだけに使います。

  • 動画の投稿、サムネイル・字幕の設定、公開の状態の切りかえ
  • 視聴データとコメントを読み、次の動画の台本や作り方を直すこと

広告に使ったり、ほかの目的に使ったりはしません。

4. 保存する場所と期間

取得した情報は、持ち主の PC の中だけに保存します。 このツールにはデータを集めるためのサーバーはなく、ほかの場所（クラウドのストレージ、データベースなど）には保存しません。

  • 認証の情報：持ち主がこのツールを使うあいだ、持ち主の PC に保存します。使うのをやめるときは削除します。
  • 視聴データ：分析のために、持ち主の PC に保存し続けることがあります。その場合も、30日ごとに、データを読む権限がまだ有効かを確かめます。
  • そのほかの情報（コメント、動画の情報など）：取得してから30日以内に削除するか、取得し直して新しくします。

保存の期間は、YouTube API サービスの開発者ポリシーに従っています。

5. 第三者への提供

取得した情報を、第三者に売ったり、渡したり、貸したりはしません。広告にも使いません。 ただし、次の場合を除きます。

  • 分析の手伝い：持ち主は、保存した視聴データとコメントの要約を、AI アシスタント（Anthropic 社の Claude）に読ませて、 次の動画の台本を直す手伝いをさせることがあります。このとき、要約の内容は、その処理のためだけに Anthropic 社に送られます。
  • 法令にもとづく場合：法令にもとづいて開示を求められたとき。

6. Google API サービスのユーザーデータに関するポリシー

このツールが Google API から受け取った情報の利用と、ほかのアプリへの転送は、 Google API サービスのユーザーデータに関するポリシー （Limited Use〔使用の制限〕の要件を含みます）に従います。

このツールは、YouTube API サービスの開発者ポリシーにも従います。

7. 端末への保存と Cookie

  • このツールは、認証の情報と、取得した情報を、持ち主の PC にファイルとして保存します（4のとおり）。ほかの人の端末には何も保存しません。
  • このツールは、第三者に広告などのコンテンツを表示させることはありません。
  • このウェブサイト（このページとホームページ）は、Cookie・アクセス解析・広告を使っていません。 ただし、ウェブサイトを置いている GitHub Pages は、安全のために訪問者の IP アドレスを記録します （GitHub Pages について、 GitHub のプライバシーに関する声明）。

8. 権限の取り消しとデータの削除

このツールに許可した権限は、いつでも取り消せます。

  1. Google アカウントのセキュリティ設定のページ （Google アカウント →「セキュリティ」→「サードパーティ製のアプリとサービス」）を開きます。
  2. 一覧から「ゆっくり解説 投稿・分析ツール」を選び、アクセスを削除します。

取り消したあと、持ち主は、このツールが保存した情報を7日以内に削除します。

9. このポリシーの変更

取得する情報や使い道を変えるときは、このページを書き直し、下の最終更新日を新しくします。

10. お問い合わせ

このポリシーと情報の扱いについてのご質問・ご意見は、このページのリポジトリの Issues でお知らせください（GitHub のアカウントが必要です）。Issues は誰でも読める場所なので、個人情報は書かないでください。
